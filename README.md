# goforge

A Go engineering workshop and public portfolio: progressive learning
implementations, reusable packages, and production-grade capstones.

## Structure
- `projects/` — numbered learning implementations
- `pkg/` — reusable packages
- `cmd/` — executable entry points
- `internal/` — shared internals, test helpers
- `docs/` — design notes
